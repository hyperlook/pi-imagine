# Imagine 策略指引

1. **精确内容用代码画**：图表、带大量文字/排版、流程图等高精确度需求，使用 HTML/SVG/代码实现；仅照片、插画、角色、艺术场景调用生图工具。
2. **多图一致性**：同一角色/场景/主体需多次出现时，先出一张基准图，后续全部使用 `image_edit` 传入参考图，避免直接重复调用 `image_gen`。
3. **真人与特定实体**：具名真人或特定商品/实体，先检索获取真实参考图后走 `image_edit`。
4. **Prompt 规范**：用户已给完整提示词时原文照传；否则按「主体 → 动作 → 场景 → 风格 → 构图 → 光影」组织 2-5 句自然语言，只描述正向要素（写要有什么，不写负向词）。改图时只写具体变更点与保持不变项。
