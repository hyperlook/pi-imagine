# Imagine 策略与工作流指引

## 一、核心工作流 (Workflow)

当用户提出生图或视觉设计需求时，遵循以下标准流程：

```
[ 用户生图意图 ] 
       │
       ▼
[ 1. 案例检索 ] ── 调用 search_prompt_cases(query, category, style) 检索 2~3 个黄金案例
       │
       ▼
[ 2. 方案匹配与决策 ] ── 分析案例构图、材质、光学与排版特性，选定最佳方案
       │
       ▼
[ 3. 变量参数化替换 ] ── 保留原案例的高质感光影/材质/负向约束，仅替换主体、文案或商品变量
       │
       ▼
[ 4. 高质量出图 ] ── 调用 image_gen (标准比例 9:16/16:9/1:1, 默认 high-quality 引擎)
```

## 二、关键策略规范

1. **优先检索黄金案例库 (Search First)**：
   - 避免凭空脑补写口语化 Prompt；
   - 遇到海报、UI、微缩景观、商品广告、信息图、3D 渲染、古典艺术等需求，**优先调用 `search_prompt_cases` 查找库中 500+ 个实测高质量案例**；
   - 提取命中的黄金 Prompt，保留其对物理材质、镜头透视、光学色散、排版层级的严密约束，只将占位符（如 `[COUNTRY]`, `[PRODUCT]`）或主体实体替换为用户所需内容。

2. **精确图表与密集排版用代码**：
   - 包含高精度数据流、严密节点连线、大量精准中文表格的图表，优先用 HTML/SVG/Canvas 等代码生成；
   - 商业广告、艺术场景、概念海报、3D 视觉、拟真照片调用 `image_gen`。

3. **多图与实体一致性 (Consistency)**：
   - 同一角色、场景或商品主体需多次出现时，先用 `image_gen` 产出一张基准图，后续全部使用 `image_edit` 传入该参考图，避免独立生图产生面容或风格漂移；
   - 具名真人或特定物理商品，先检索获取真实参考图后走 `image_edit`。

4. **参数规范 (Parameters)**：
   - 比例 `aspect_ratio`：默认 `auto`（模型根据提示词语义自动选择最适画幅，如识别 prompt 中的 widescreen/portrait 关键词）；固定画幅可选：`1:1`（方形头像/图标）、`16:9`（横幅壁纸/视频封面）、`9:16`（手机竖屏/小红书）、`4:3` / `3:4`、`3:2` / `2:3`（经典摄影胶片）、`21:9`（电影级超宽银幕）、`9:21`（长图）、`2:1` / `1:2`；
   - 默认走 `grok-imagine-image-quality` 引擎，兼顾极高画质与锐利文字排版；要海报级极限画质与文字渲染时选用 `grok-imagine-image-2.0`。
